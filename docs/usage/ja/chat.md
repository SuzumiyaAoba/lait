# 会話セッション

[ドキュメント目次に戻る](./README.md)

## `--session`（会話の保存と再開）

`--session <NAME>` を指定すると、単発の `lait` 呼び出しでも会話履歴を引き継げます。

```sh
lait --model "モデル ID" --session demo "1+1は?"
lait --model "モデル ID" --session demo "それに2を足すと?"
```

- 保存先はプロジェクトローカルの `.lait/sessions/<NAME>.jsonl`（1行1メッセージの JSON Lines）です。
- リクエスト送信前に、そのセッションにこれまで記録されている全ターンを読み込み、システムプロンプトの直後・今回のプロンプトの直前に差し込みます。
- リクエストが成功した場合のみ、今回のユーザーメッセージとモデルの応答をセッションファイルに追記します（失敗したターンは記録されません）。
- `--stream` と併用できます（ストリーミング中に表示された内容全体が、その回のモデル応答として記録されます）。
- システムプロンプト（`--system`/`--system-file`/`default.system`）はセッションファイルには保存されません。毎回のコマンドラインから改めて渡してください。
- セッション名に使えるのは英数字・`_`・`-` のみです。

## `lait sessions`（セッションの一覧・確認・削除）

```sh
lait sessions list              # 保存されている全セッションとターン数を表示
lait sessions show demo         # demo セッションの全ターンを表示
lait sessions delete demo       # demo セッションを削除
```
