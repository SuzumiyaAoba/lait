---

## `--file`（ファイル内容のコンテキスト添付）

`--file <PATH>` を指定すると、ファイルの内容をプロンプトのコンテキストとして添付できます。繰り返し指定すると複数ファイルを添付できます。

```sh
lait --file src/main.rs --file README.md "このコードを説明して"
```

各ファイルはファイル名付きのフェンスドコードブロックとして、プロンプトの末尾に追記されます（内容に ` ``` ` が含まれる場合はフェンスの長さを自動的に広げます）。標準入力（パイプ）と併用した場合は「プロンプト引数 → パイプされたテキスト → ファイルの内容」の順で連結されます。

- バイナリファイル（UTF-8 として読めない内容）はエラーになります。画像を渡したい場合は次の `--image` を使ってください。
- 添付ファイルの合計サイズには上限（10MiB）があり、超過すると明確なエラーになります。

## `--image`（vision モデル向けの画像入力）

`--image <PATH_OR_URL>` を指定すると、vision 対応モデルに画像を渡せます。繰り返し指定すると複数枚を添付できます。

```sh
lait --model "vision対応モデル" --image photo.png "この画像を説明して"
lait --model "vision対応モデル" --image https://example.com/cat.png "何が写っていますか?"
```

- ローカルファイルパスは内容を base64 エンコードした data URL（`data:image/png;base64,...`）に変換して送信します。
- `http://`/`https://` から始まる値はそのまま `image_url` として渡します。
- 画像形式は PNG / JPEG / WebP / GIF に対応し、まずマジックバイトで判定、判定できない場合は拡張子から推測します。いずれでも判定できない場合はエラーになります。
- `--image` を1つ以上指定すると、ユーザーメッセージの `content` は文字列ではなく `[{"type":"text",...}, {"type":"image_url",...}, ...]` の配列になります（画像を指定しない通常のリクエストの形は変わりません）。
- `--stream` と併用できます。`--mcp`/`--subagent`（ツール呼び出し）とも併用できます。
